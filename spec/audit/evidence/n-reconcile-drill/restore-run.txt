  (a block's *bodies* are not in the heights route — /api/block/{hash} carries the terms, the heights
   route carries counts. The owners re-submit; this tool does not claim to replay them.)

== 6. the fiat, printed before it is applied ==
  This is NOT a sync. The joiners adopt A's chain state wholesale, so what they agree about
  afterwards is A's view of the chain — including any block above the point that A
  accepted and its peers did not. The blocks this drops are enumerated in section 4; that count is
  the write set the owners re-submit. Running this is the operator asserting that A is the
  chain. It is a stopgap because it depends on the data-dir layout being movable — which #287's
  design deliberately avoided depending on — and not a substitute for an agreed anchor.
