## Established

Agoric's published client, over its own `websocket` netlayer:

- completed the **in-band challenge** — it sent `init:peer-auth`, this node signed the bytes it
  received, and the client accepted the answer (`>>> Server received VALID location signature`);
- completed the **CapTP handshake**: `handling handshake message of type op:start-session`, then
  `session established`;
- imported the node's bootstrap (`imported o-0 Object [Alleged: Remote Bootstrap]`).

So the transport, the challenge/response and the session handshake interoperate with the
implementation it was written against.

## A defect this run found, and it is the reason to have run it

The first attempt **failed**, and the failure was this repository's:

    Error#1: InitPeerAuthSigEnvelope: read failed at index 0 of <unknown>
      Error#2: OcapnSignature: read failed at index 75 of <unknown>
        Error#3: Unexpected character "6", expected "[" at index 75 of <unknown>

`desc:sig-envelope`'s signature field is a **gcrypt s-expression**
(`['sig-val ['eddsa ['r …] ['s …]]]`), not raw bytes — the same shape `op:start-session` already
carries, and this module was writing `Value::Bytes`. **The module's own tests could not have caught
it**: they agreed with themselves. `ocapn/src/websocket.rs` now uses `session::signature_syrup` /
`signature_bytes`, which is where that shape already lived.

## NOT established

**The fetch does not complete.** After `session established` the client's `enlivenSturdyRef` never
resolves: no `FETCHED` line, and the node logs nothing after its listener line. The run was stopped by
a 120 s bound rather than finishing. So a **CapTP delivery over this transport is not yet demonstrated
end to end**, and the cause is not yet found.

Two things are therefore untested and should not be assumed from the lines above: that this node answers
a `fetch` over websocket, and that a call over it returns. `node/tests/ocapn_listener.rs` does exercise
both — but with *this repository's* client, so it does not close the gap.

Recorded as a residual on the transport rather than as a passing run.
